# Provenance of `@noblecloak/theme`

This package is a deliberate subset of an internal design system, written so that the drift between the two
stays visible. It records, for every file this package carries, where its pattern came from, and under what
licence it is carried here. This file is not published (it is not in `files`).

## Source

- **Design system:** the NobleCloak internal design system.
- **Commit read:** `604c7c8865712f99b943398c413e9fb413c48575` (`origin/main`, and the last commit touching
  `packages/design-system`, on 2026-10-20).
- **Design-system licence:** Apache-2.0. `packages/design-system/LICENSE` at that commit is the full Apache
  License 2.0 text, and its `package.json` declares `"license": "Apache-2.0"`.

The design system is never a dependency of this package (the repository's private-dependency guard forbids
private dependencies), and no file of it is copied here.

## How the files were made

The design system's components carry Tailwind class strings and sit on Radix primitives. This package is
hand-written CSS on native elements, with no Tailwind and no Radix, so **every primitive here is a fresh write
informed by the design system's pattern** (its component names, props and behaviour), not a copy of its code.
No TypeScript, JSX or CSS was carried substantially as-is, so no row below is "copied".

Columns: **Upstream origin** is where the design-system file itself came from: _house-authored_ (written in
the design system), _shadcn-style pattern_ (the design system's file follows the shadcn/ui component pattern,
MIT), or _Radix MIT_ (the design system's file wraps a Radix UI primitive, MIT). **Carried as** is what this
package did with it.

## Notices

- **Radix UI (MIT):** no Radix-derived file is carried; this package has no Radix dependency and copies no
  Radix code. Nothing is added to `NOTICE`.
- **shadcn/ui (MIT):** no shadcn/ui code is carried; the "shadcn-style" rows took component names and props
  only, and their markup and styles are written fresh. Nothing is added to `NOTICE`.
- **Fonts:** `src/styles/fonts.css` references Space Grotesk and JetBrains Mono (both SIL Open Font License 1.1)
  by URL; no font file is carried or bundled.

If a later change carries a Radix-derived or shadcn-derived file substantially as-is, it adds a row marked
"copied" here and the upstream notice to `NOTICE` (root and package) in the same change.
